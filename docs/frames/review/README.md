# Review gallery

Generated by `node harness/montage.mjs`. Each sheet stacks frames top to bottom in the order listed.

> These frames are painted by the project rasterizer, not by a terminal, so they show renderer *intent* in fixed-size cells. A real terminal can differ — notably sextant glyphs render double-width in mintty and break the grid even though they look solid here. Run `node src/statusline.mjs --doctor` (it measures glyph width) to check yours. See `docs/ART-DIRECTION.md`.
